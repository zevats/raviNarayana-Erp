# Ravinarayan — Android app

A native Android app (Capacitor 7) for the Ravinarayan ERP. It installs from an APK like any
other app, has its own launcher icon and splash screen, handles the Android back button, status
bar and notification permission natively, and receives delivery alerts through Firebase Cloud
Messaging with its own alert sound — also when the app is closed or the phone is locked.

The screens are the ERP hosted on Render (`server.url` in `capacitor.config.json`), so every
module, permission rule and API works exactly as on the web, and improvements to the ERP reach
the app without reinstalling. If the server cannot be reached, the app shows its own offline page
(`www/offline.html`) with *Try again*.

## What is native

- **Splash** — Android 12+ animated splash (the R draws itself, the sun appears); static on 8–11.
  Green for the ERP; orange for a phone whose last signed-in user is a delivery partner
  (`MainActivity` reads the edition the web app stores through the `RnApp` plugin).
- **Launcher icon** — adaptive vector icon with a monochrome layer for Android 13 themed icons.
- **Notification channels** (created in `MainActivity`):
  - `delivery_alerts` — new stops; high importance, lock-screen visible, custom sound
    `res/raw/delivery_alert.wav` (generated by `scripts/make-alert-sound.js`), vibration.
  - `delivery_updates` — cancellations; default sound.
  Phone settings (silent mode, Do Not Disturb, per-channel sound) are respected.
- **Back button** — closes an open sheet or menu first, then goes back, then minimises the app.
- **Status bar** — coloured per screen (green / orange / light) by the web app.

## Delivery alerts (Firebase) — one-time setup

The APK is built and works without Firebase; alerts switch on after these steps.

1. Open <https://console.firebase.google.com>, **Add project** (any name, e.g. *Ravinarayan*).
2. In the project: **Add app → Android**, package name **`com.ravinarayan.erp`**, register.
3. Download **`google-services.json`** and put it at **`mobile/android/app/google-services.json`**.
4. **Project settings → Service accounts → Generate new private key**. Open the downloaded JSON.
5. On **Render → Environment** add **`FIREBASE_SERVICE_ACCOUNT`** = the whole JSON content
   (paste as is). Save; Render redeploys. Never put this key in the app or the repository.
6. Rebuild the APK (below), install it over the old one, sign in as the delivery partner and
   allow notifications. Assign a stop to them from the Manager portal: the phone rings.

How it works: after sign-in the app asks for notification permission (Android 13+), gets its FCM
token and sends it to `POST /api/push/token` (table `push_tokens`, migration 0015, applied
automatically on Render start). When stops are assigned to someone (manual, batch, a new order's
automatic assignment, a retry) the server sends one alert per phone of that person; a cancellation
sends a "Delivery cancelled" update. Tapping an alert opens that stop. Signing out removes the
phone's token; tokens Firebase reports as invalid are deleted.

## Build a new APK

Requirements: JDK 17+ and the Android SDK (platform 35, build-tools 35). On this machine:
JDK 23 at `C:\Program Files\Java\jdk-23`, SDK at `%LOCALAPPDATA%\Android\Sdk`.

```bash
cd mobile
npm install          # first time only
# raise versionCode (+1) and versionName in android/app/build.gradle
npm run apk
```

Output: `mobile/dist/ravinarayan-<version>.apk` and `apps/erp/public/download/ravinarayan.apk`
(+ `ravinarayan.json` with version, size and SHA-256). Commit those two files and push; Render
serves the APK at **`/download/ravinarayan.apk`** and the download page at **`/download`**.

## Signing key — back it up

Release builds are signed with `~/.ravinarayan/ravinarayan-release.jks`; its passwords are in
`~/.ravinarayan/keystore.properties` (both outside the repository, never commit them).
**Copy both files somewhere safe.** Android only installs an update over the app if it is signed
with the same key; without it, people must uninstall and install again.
To build on another machine, copy both files to `~/.ravinarayan/` there (or point
`RN_KEYSTORE_PROPERTIES` at the properties file).

## Changing the server address

Edit `server.url` and `server.allowNavigation` in `capacitor.config.json` and `www/*.html`,
then rebuild.
